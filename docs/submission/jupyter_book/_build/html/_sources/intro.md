# AI-Powered Plant Disease Detection

This Jupyter Book documents an end-to-end computer vision prototype for mobile-assisted plant disease diagnosis.

## What This Project Covers
- Problem framing and objective definition
- Data loading and preprocessing
- Model development (CNN, MobileNetV2, Hybrid)
- Training and evaluation workflow
- Inference API and frontend integration
- Explainability with Grad-CAM
- Performance analysis, limitations, and roadmap

## Repository Entry Points
- Backend: `app/main.py`
- ML code: `ml/src/`
- Documentation: `docs/`
